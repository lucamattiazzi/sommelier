A wordplay on Pairing and Excel.

Work in Excel with YOUR personal agent.

Connect Excel to your agent, running in your favourite harness. You don't need to give Copilot access to data you don't want to share!

Ask it to read cells, propose changes and create charts, right in your workbook, without ever leaving your favourite spreadsheet editor.

Heavily inspired by Marimo Pair, that does something similar with Marimo notebooks, which are way cooler than Excel files.

  1. Add it to Excel. Download the XML manifest and sideload it in Excel.
    Download Excel add-in View on GitHub ↗

    Free and open source · Install manually in Excel

  2. Pair your agent. Open Sommelier, copy the setup prompt and paste it into your agent. No skill installation required.
  3. Work in the chat. Ask questions and review proposed workbook changes before approving them.

Workbook traffic is encrypted between Excel and the local bridge. The relay cannot read it. Your chosen agent controls what it sends to its model provider.

Requires Node.js 22.12+ and an agent with shell access. Keep the agent listening while you work. The setup prompt includes a private connection key shared with that agent.
