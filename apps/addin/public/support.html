Sommelier support

Sommelier connects your existing coding agent to the workbook open in Excel. The browser preview uses synthetic data and never opens a real workbook.

The terminal does not connect

  1. Start your harness adapter and check its named profile with sommelier status --name NAME. See setup for installation.
  2. Click Reconnect in Excel. If another pane is connected to the same terminal, disconnect it first.
  3. Check that the terminal can reach the relay over WSS. Development connections use loopback WS.
  4. If storage was cleared or a credential was forgotten, perform the one-time association again.

Connected, but no reply

The bridge is the connection, while your harness supplies the agent. Keep the harness adapter running and check its terminal for errors. If using the portable skill fallback, invoke the skill again when it stops waiting.

A change is waiting

Review the before/after preview and approve or reject it in Excel. Approval is required by default. Automatic approval applies to the current connection only.

A request timed out

Read the affected range before retrying a write. A change may have completed even when the reply was interrupted. Use operation history to undo supported range changes; chart undo is not available in this beta.

Reporting a problem

Include your operating system, Excel version, harness version, exact error and steps using synthetic data. Remove pairing URLs, tokens, workbook contents and model credentials. For self-hosted deployments, send the report to your deployment maintainer.

Report reproducible issues on GitHub. Use synthetic data and remove private connection URLs. This beta is not yet listed in Microsoft Marketplace.
