Connect your agent

  1. Open Sommelier in Excel and choose Copy agent prompt.
  2. Paste it into your existing agent and let it run the setup.
  3. Keep the TaskPane open. When connected, send your requests in its chat.

No preinstalled skill is needed. Your agent needs shell access and Node.js 22.12+. The prompt installs the published bridge in a temporary directory and includes the workbook commands and listening loop. It does not start another agent.

The prompt contains a private connection key. Pasting it shares the key with your chosen agent and potentially its model provider. See data and privacy.

Work in Excel

Ask your agent to read a range, update cells or create a chart. The TaskPane asks you to approve changes. Connection settings, workbook context and recent operations are under Options. To rename the default connection, use Options → Connection name.

Reconnect later

Resume the bridge and listening loop in your agent, then choose Options → Saved terminals → Reconnect in Excel. The optional Sommelier skill can reuse your saved local profile without another setup prompt. A connected bridge cannot wake a stopped agent.

If clipboard access is unavailable, expand Show prompt and copy the text manually.

Hosting

The TaskPane uses the relay hosted by your operator or your own instance. End users run only the local bridge. The server address is included in the prompt; there is no fixed operator domain.
