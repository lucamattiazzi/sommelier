Your agent, inside Excel

Associate a terminal once. Start its adapter when you need it, then reconnect from Excel. No setup prompt to paste into your agent each time.

1. Install the local adapter

Requires Node.js 22.12+ and your chosen harness installed and signed in. The Pair service is hosted by your operator or on your own infrastructure; you do not need to start a Sommelier server on this computer.

Install the beta adapter:

npm install -g @lucamattiazzi/sommelier@beta
Alternative: install from a trusted checkout

Requires pnpm. Run from the repository root:

pnpm install --frozen-lockfile
pnpm bridge:build
pnpm --filter @lucamattiazzi/sommelier-protocol --filter @lucamattiazzi/sommelier build

Use pnpm agent instead of sommelier below. Use the beta tag explicitly when installing from npm.

2. Associate once

  1. In Excel, name the connection and choose Pair a terminal.
  2. Run sommelier pair --name desk in your terminal.
  3. Choose Copy connection URL in Excel and paste it at the terminal prompt. Keep this URL private.

3. Start your adapter

sommelier codex --name desk
# Or:
sommelier opencode --name desk
sommelier claude --name desk

OpenCode: the adapter starts and stops its local harness process automatically. Run it from your project, or pass --directory /path/to/project. Advanced: --server http://127.0.0.1:4096 attaches an existing local OpenCode API that you manage yourself.

Claude Code: the adapter uses Channels, currently a research preview. Accept Claude’s channel consent and keep its session open. Organization policies may restrict channels.

Codex: the adapter starts an App Server and remembers its conversation. It does not take over an arbitrary terminal already running Codex. Native command/file approvals are declined in v1; workbook approvals stay in Excel.

Reconnect later

Repeat only the adapter command, then select your saved terminal and choose Reconnect in Excel. You can enable automatic connection when the TaskPane opens. Each profile serves one open workbook at a time.

sommelier list
sommelier stop --name desk
sommelier forget --name desk

Stop the adapter before forgetting. Also forget the connection in Excel to remove both copies. A remembered association cannot start a stopped process or wake your computer.

Work and evaluate

Ask your agent to inspect a range, update cells or create a chart. Changes are previewed and require approval in Excel by default. The agent can read excel_guide for tool documentation.

sommelier trace --name desk --out run.jsonl

Traces contain metadata by default. Add --include-content only when you intentionally want to save workbook contents and messages locally.

Use your own server

This add-in uses the Sommelier instance that serves it. To self-host, deploy Sommelier with your own domain and install the manifest generated by that instance. The connection URL includes the selected server; the adapter remembers it without a separate server setting. A different instance requires a new association.

Skill-only fallback

Install the portable skill with pnpm harness:install codex (or opencode, claude, pi). The alternative setup in the TaskPane works without a native adapter, but you must invoke the skill again when the agent stops waiting.
