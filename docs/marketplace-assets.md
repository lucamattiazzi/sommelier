The icon manifest uses separate resources at their actual dimensions. `pnpm manifest:check` checks
deterministic generation. The browser smoke test checks that all referenced shipping assets return
non-empty responses. These checks do not replace Microsoft's manifest validator.

## Draft listing copy

**Name:** Sommelier

**Short description:** Connect your existing coding agent to Excel. Reconnect trusted terminals and
review workbook changes before applying them.

**Description:** Work with the workbook in front of you using the agent you already use in OpenCode,
Codex or Claude Code. Pair a terminal once, then reconnect it from Excel. Ask questions in the task
pane, inspect bounded ranges, review proposed changes and approve them before they are applied.
Sommelier encrypts workbook operations and conversations between the task pane and your local bridge.
Your chosen agent controls any onward transfer to its model provider. Requires a compatible coding
harness, Node.js 22.12+ on the bridge machine, and access to a Sommelier relay. Keep the local adapter running for the agent to receive messages.
The portable skill is an alternative for tool-driven workflows.

## Still required for a public listing

- Real public HTTPS origin and production manifest, publisher identity and support contact.
- Deployment-specific legal/privacy terms and a retention policy for any infrastructure access logs.
- Screenshots captured in actual supported Excel hosts. Browser preview images are development
  evidence, not proof of Office compatibility.
- Microsoft manifest validation and supported-host testing, including real formula recalculation.
- Review of the cryptographic implementation and Windows ACL behavior before claiming those guarantees.

No production URL, publisher information, Marketplace submission or live Excel screenshots are
fabricated by this repository.
